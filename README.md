# Quản lý Golden Bee

Ứng dụng quản lý Trung tâm can thiệp sớm Golden Bee (Đà Nẵng).

- `trung-tam-tri-lieu.html`: bản đóng gói chạy trực tiếp trên trình duyệt (phiên bản 8).
- `src/build/`: mã nguồn chia nhỏ, ghép lại thành file HTML.
- `tools/`: script xử lý dữ liệu VB-MAPP (đọc Excel, tạo mã JS).
- `test/`: kiểm thử tự động bằng Playwright.

Dữ liệu hiện lưu trong trình duyệt (localStorage). Chưa có máy chủ.
